# Roadmap

## Текущее состояние: 6.0.1

- Подписанная release-сборка, CI.
- Исправлены: версия в настройках, выбор декодера, напоминания Android 13+, добавление плейлиста с главного экрана.
- Устранено переполнение диска при загрузке EPG.
- Проверено на эмуляторе Android 15; проверка на физическом устройстве заказчика ещё предстоит.

## Будущее: автомобильный сценарий (Headswap-inspired)

Статус: **план, не реализовано в 6.0.1**. Источник идей — [Headswap](https://t.me/headswap). Код и визуальный стиль Headswap не копировались; переносить предполагается только продуктовые сценарии, адаптированные под IPTV и требования безопасности.

Приоритетные кандидаты:

1. **Проекция экрана телефона / запуск приложений на экране магнитолы.** Исследовать допустимые механизмы Android Auto / head unit, ограничения платформы и безопасность.
2. **Автоматическая уборка.** Уточнить сценарий: очистка кэша, упорядочивание интерфейса или обслуживание данных. Не включать без явного пользовательского контроля.
3. **Живые интерактивные плитки.** Канал, EPG, избранное, продолжить просмотр; одинаковая доступность с пульта и тача.
4. **Навигационные плитки / интеграция с навигатором.** Только если это не отвлекает от просмотра и не нарушает требования безопасности.
5. **Пресеты автомобильных экранов.** Поддержка нестандартных разрешений и соотношений сторон; проверочная матрица реальных экранов.
6. **Активация / настройка через отладку по Wi-Fi.** Рассматривать только после отдельного security-review; не делать обязательным сценарием.
7. **Быстрый выход / двойной Back.** Проверить конфликт с выходом из плеера и случайным покиданием приложения.
8. **«Стеклянная» стилистика.** Только после проверки контраста, читаемости поверх видео и видимости фокуса.

Ограничения: любые автомобильные функции должны учитывать предупреждение о неофициальных возможностях Android Auto, требования законодательства и безопасности дорожного движения.

## Прочее будущее

- Ограничение размера / окна хранения EPG для устройств с небольшим накопителем.
- Фоновое обновление EPG по расписанию.
- Экспорт / резервное копирование плейлистов и настроек.
- Отдельный security-review Wi-Fi-передачи плейлистов.
